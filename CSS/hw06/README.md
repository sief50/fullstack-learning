# Web Developer Portfolio

## 📌 Project Overview

This project is a responsive Web Developer Portfolio created using HTML5 and CSS3.

The website presents a developer's introduction, services, projects, and contact information in a simple and clean layout.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome
* cdnjs CDN

## 📚 Concepts Practiced

In this project, I practiced:

* Creating a multi-section website structure using HTML
* Using semantic HTML elements
* Creating navigation links between sections using `id` and anchor links
* Using CSS Flexbox for layout and alignment
* Using `justify-content` and `align-items`
* Creating and styling cards
* Using background images with `background-image`
* Using `background-size: cover`
* Styling buttons, links, images, and text
* Using `margin`, `padding`, `width`, and `height`
* Creating rounded elements using `border-radius`
* Using `box-shadow`
* Creating hover effects using `:hover`
* Using CSS transitions
* Using Font Awesome icons through cdnjs
* Creating responsive layouts using media queries
* Changing layouts from rows to columns on smaller screens
* Using `scroll-behavior: smooth` for smooth navigation

## 📋 Features

The portfolio website includes:

* Hero section with developer introduction
* Navigation bar
* Services section
* Web Development service card
* UI Design service card
* Responsive Design service card
* Projects section
* Portfolio Website project
* Restaurant Website project
* E-commerce Website project
* Weather App project
* Contact section
* LinkedIn, Email, and GitHub contact cards
* Social media icons
* Responsive design for mobile devices
* Hover effects and smooth scrolling
