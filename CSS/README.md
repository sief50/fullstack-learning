📌 Project Overview
This project demonstrates basic CSS styling including hover effects, list markers, image sizing, and absolute positioning.

🛠️ Technologies Used

* HTML5
* CSS3

📚 Concepts Practiced

* `:hover` for links and background color change
* `list-style-type` and `::marker` for custom list bullets
* `position: absolute` and `z-index`
* Styling images with `width`
